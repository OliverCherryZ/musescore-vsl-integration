# Changelog

## v0.1.0 — 2026-11-18

Binary distribution supplement:

- Add a Windows x64 application ZIP with runtime libraries, MuseScore Basic, public configuration, selector, and the three companion plugins.
- Add a standalone VST3 ZIP and a complete corresponding source ZIP.
- Verify relocation with a restricted PATH, native GUI score import, PDF export and 48 kHz float WAV export. MuseSounds showed an unavailable notice and is not claimed as validated.
- Expand the project purpose, feature explanations, general VST3 scope, and end-user installation instructions. The source tag and application/plugin implementation remain unchanged.

First public source snapshot of the local MuseScore / VSL integration.

- Publish the current MuseScore 4.7.7 source changes, including articulation metadata, selector bindings, sample preparation, export coordination, and shutdown lifetime fixes.
- Publish the Smooth Bridge, Dynamics Smoother, and legacy Offline Bridge Fix sources with portable build instructions.
- Publish the installed articulation selector and mapped catalog, with local audit metadata removed from distribution copies.
- Add upstream provenance, GPL licensing, third-party notices, source reconstruction checks, and explicit validation limits.

This release packages an existing local implementation. It does not claim that every catalog route has been auditioned or that all historical native tests were repeated on a newly rebuilt release binary.
